- **Eight open source extensions for Pterodactyl 2.0**, published by [Rustix Development](https://github.com/Rustix-Development):

| Extension | What it does |
| --- | --- |
| [Wipe & Season Manager](https://github.com/Rustix-Development/pterodactyl-wipe-season-manager) | Scheduled wipes for Rust and other games: warns players, backs up, deletes chosen files, changes seed or map, restarts and posts to Discord, with a full history |

| [Next Wipe](https://github.com/Rustix-Development/pterodactyl-next-wipe) | Wipe countdown on the console, with an optional public page |
| [Custom Links](https://github.com/Rustix-Development/pterodactyl-custom-links) | Your own buttons and tabs on server pages and the dashboard |
| [Connect Buttons](https://github.com/Rustix-Development/pterodactyl-connect-buttons) | One-click Join and Copy address for Minecraft, Rust, Source games, FiveM, TeamSpeak and Mumble |
| [SFTP Quick Connect](https://github.com/Rustix-Development/pterodactyl-sftp-quick-connect) | Open server files in FileZilla, WinSCP, Cyberduck or a terminal in one click |
| [Staff Notes](https://github.com/Rustix-Development/pterodactyl-staff-notes) | Private admin notes and VIP, Watch or Problem flags on users and servers |
